What “independent” means here

The new causal IR was manually derived from raw base.bas and its host/simulator, with a separate lowering and parent-free reader. It does not import the existing IR compiler, binding templates or policy IRs. The models share a syntax parser and the real game VM. This was the same research session and agent, so it is an independent construction, not a blinded replication.

The fresh model keeps situation, belief, goal, skill, strategy, execution and update separate. It explicitly represents observation timing, earlier inventory flags, cumulative action order and persistent engine intent. Intent inferred from behavior is labeled as interpretation. No opponent beliefs or win advantage are inferred from equivalent code.

A separate full-inventory probe consumed its last ration while the policy retained hasHeal=1 and emptySlot=0. The old consume contract already described the before-use flags; this review made the timing explicit in the broader execution model and verified it with the actual host.

Changes incorporated into the current loop

The working base, Duelist and Reserve IRs now carry four evidence-linked beliefs covering independent reconstruction, observation timing, action effects and immediate equipment resources. Their tested BASIC bytes are unchanged. New immutable bundles include temporal execution facts alongside the existing semantic views; pre-reconciliation IRs were preserved.

The current extractor can now lift an edited, unmarked baseline-family BASIC program through the independent reader and then check every region against the current contracts. An unmarked healing threshold edit was recovered into IR and regenerated exactly. Unknown statements, unsupported timing changes and ambiguous behavior still fail closed. This reader supports the documented baseline family; it is not an arbitrary BASIC decompiler.

Implications for the next policy experiment

Two hypotheses are now sharper: replacing consumed items using current inventory state, and comparing HP equipment with consumables as immediate sustain. They need isolated behavioral changes and fresh evaluations; neither is promoted by this fidelity review. The earlier four-equipment cap’s win benefit remains unconfirmed despite its measured inventory-access benefit.
