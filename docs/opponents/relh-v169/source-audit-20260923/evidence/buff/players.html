About this snapshot Sources, units & coverage

League is the first category: score, win/loss, then average glory. Score determines column order, highest first. It is the average recorded evaluation score across each player's games in this window. The current per-game formula is max(0, floor(total XP − 200 × game minutes)). Earlier games retain their recorded score precision. Equal scores are ordered by name; players without a score appear last.

Win/loss shows the win percentage, with loss percentage below as L and draw percentage as D when present. All three use the column's total game count; hover for the original counts. Glory is each game's recorded score on a win and zero on a loss or draw, averaged across all observed games. A missing score on a win is excluded from the glory average.

Each player's policy versions are combined by default. Select a player and choose an exact policy version to update that column's statistics and game count. Versions are listed by their latest game in this snapshot; newer versions outside this window are not included. Columns re-sort by their displayed scores, and version choices stay in place as you compare players until you reload. Choose All versions to restore a column's combined statistics.

Every current league player is listed, including players with no games in this window. Built-in opponents appear as separate baseline columns. Values are arithmetic means across hero-games, so each appearance carries equal weight. Order rates count accepted commands per minute alive; total, repeated and rejected order rates include every issued command. Rejections are commands the game engine refused. CPU is the recorded percentage of the instruction allowance. Missing telemetry is excluded from that metric's mean.

Draft shares use the final drafted class. Target shares use games with at least one accepted attack-target order. Movement uses full-precision positions and excludes death/respawn and portal jumps. Proximity uses the original tower locations, including towers later destroyed. Low-health walk orders are a behavior proxy; they do not necessarily indicate retreat.

Replay engines can change during the window; their versions and coverage are shown above. League score comes from the platform's recorded reward. These are descriptive observations across different drafts and teammates. The latest tournament remains a separate fixed report.
